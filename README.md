# Tejas Pinjarkar — Portfolio

Personal portfolio website built with Next.js, Tailwind CSS v4, and MDX.
## Overview

- `app/` — Next.js App Router pages
- `components/` — Reusable UI components
- `data/blog/` — MDX blog posts
- `lib/site-config.ts` — Personal info and site metadata

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs on [http://localhost:3000](http://localhost:3000) using Turbopack.

## Built With

- [Next.js 16](https://nextjs.org) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com)
- [MDX](https://mdxjs.com) via next-mdx-remote
- [Motion](https://motion.dev)
- [Tabler Icons](https://tabler.io/icons)

## Deploy

Deploy to [Vercel](https://vercel.com) or any platform that supports Next.js. Update `siteUrl` in `lib/site-config.ts` with your production domain.
